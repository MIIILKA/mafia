# Мафія Онлайн

Повноцінний веб-застосунок для гри в мафію онлайн: кімнати, ролі, ніч/день/голосування в реальному часі, камери гравців і панель модерації для ведучого.

- **Клієнт:** React + SCSS + Vite, підключення через Socket.IO
- **Сервер:** Node.js + Express + Socket.IO, стан кімнат зберігається в пам'яті
- **Відео:** камери гравців у сітці, WebRTC mesh — відео йде напряму між браузерами, сервер лише "знайомить" їх (сигналінг)
- **Перепідключення:** якщо гравець втратив зв'язок, він може зайти знову і повернутись у гру з тим самим статусом і роллю
- **Ведучий:** окрема роль-модератор — не грає, бачить усі ролі, має блокнот нічних дій і кнопки керування гравцями

## Структура

```
mafia-game/
  server/   — Node.js бекенд (Socket.IO, логіка гри)
  client/   — React застосунок (SCSS стилі)
```

## Запуск локально

### 1. Сервер

```bash
cd server
npm install
npm start
```
Сервер підніметься на `http://localhost:4000`.

### 2. Клієнт

У новому терміналі:
```bash
cd client
npm install
npm run dev
```
Клієнт відкриється на `http://localhost:5173`.

Скопіюйте `client/.env.example` у `client/.env`, якщо треба змінити адресу сервера чи додати TURN (див. нижче).

## Як грати

1. Один гравець створює кімнату — стає **ведучим** (не грає, лише керує) і ділиться 5-символьним кодом.
2. Інші приєднуються за кодом (мінімум 4 гравці, **без урахування ведучого**).
3. Ведучий натискає "Почати гру" — ролі роздаються автоматично:
   - **Мафія** — 1 на кожні 4 гравці
   - **Дон мафії** — з'являється, коли в мафії 2+ учасники (тобто від 8 гравців); керує мафією і вночі перевіряє, чи гравець — шериф
   - **Лікар** — з'являється від 5 гравців
   - **Шериф** — з'являється від 6 гравців
   - решта — мирні жителі
4. Цикл фаз: **Ніч** (мафія/дон обирають жертву, лікар лікує, шериф перевіряє, дон перевіряє на шерифа) → **День** (обговорення в чаті) → **Голосування** → знову ніч.
5. Гра завершується, коли всю мафію знищено, або коли мафія зрівнюється/переважає мирних.
6. Вбиті вночі позначаються як **"ВБИТО"**, вигнані голосуванням — як **"ВИГНАНО"** (окремі статуси, видно на камері й у списку гравців).

## Роль ведучого

Ведучий — окрема роль, не бере участі в грі як гравець, завжди бачить усі ролі гравців. У ведучого є:

- **Блокнот нічних дій** — під час ночі видно, кого обрала мафія/дон, кого лікує лікар, кого перевіряє шериф і дон, в реальному часі. Після завершення ночі запис лишається в історії блокнота (хто кого перевірив, хто вбитий, хто вигнаний).
- **Кнопки керування гравцем** (значок ⚙ на плитці кожної камери, крім своєї): вимкнути мікрофон/камеру гравцю примусово, позначити вбитим/вигнаним/повернути живим вручну, вилучити гравця з кімнати.

Якщо ведучий вийде з кімнати, роль ведучого автоматично переходить до наступного гравця.

## Перепідключення

Кожен браузер отримує свій стійкий ідентифікатор (зберігається в `localStorage`). Якщо гравець втратив зв'язок (закрив вкладку, зник інтернет), сервер тримає його місце **60 секунд** — за цей час можна знову відкрити застосунок (той самий браузер) і гравець автоматично повернеться в кімнату з тією ж роллю та статусом. Якщо за 60 секунд не повернувся — місце звільняється, і якщо це був ведучий, роль переходить іншому гравцю.

Обмеження: таймер фази (ніч/день/голосування) не зупиняється на час відключення гравця.

## Камери гравців

При вході в кімнату браузер попросить дозвіл на камеру/мікрофон. Якщо камери нема — гравець підключається лише зі звуком; якщо нема нічого — все одно приєднується як плитка-заглушка з першою літерою імені і бачить чужі камери.

- Відео йде **напряму між браузерами** (WebRTC), сервер не бачить і не зберігає відео/аудіо.
- Mesh-схема (кожен з кожним) добре працює для невеликих груп (~до 8-10 гравців). Для більшої кількості потрібен окремий медіа-сервер (SFU) — інша архітектура.
- Камера працює тільки на `https://` або `localhost` — якщо деплоїте, потрібен SSL.

### TURN-сервер (опційно)

TURN потрібен, коли пряме з'єднання між двома гравцями не встановлюється напряму (жорсткий NAT/файрвол — типово для деяких мобільних мереж чи офісних мереж). Без нього окремим парам гравців може не показувати відео одне одного, хоча решта працюватиме нормально.

Для гри 1-2 рази на тиждень із друзями безкоштовного тарифу вистачить із запасом. Кроки:

1. Зареєструйтесь безкоштовно на [metered.ca](https://www.metered.ca/tools/openrelay/) (є free-тариф ~50GB/міс) або іншому TURN-провайдері з безплатним планом.
2. Отримайте TURN URL, username і credential зі свого кабінету.
3. Впишіть їх у `client/.env`:
   ```
   VITE_TURN_URL=turn:your-turn-host:80
   VITE_TURN_USERNAME=...
   VITE_TURN_CREDENTIAL=...
   ```
4. Перезапустіть `npm run dev` — TURN підхопиться автоматично.

Якщо не налаштовувати — застосунок працюватиме на самому лише безплатному Google STUN, і в переважній більшості випадків (домашній Wi-Fi, мобільний інтернет) цього достатньо.

## Деплой (безкоштовно)

Щоб грати не тільки на одному комп'ютері:
- **Сервер:** Render.com або Fly.io мають безплатні тарифи. Нюанс: безплатний інстанс "засинає" після ~15 хв без активності, перший гравець чекає 30-60 сек, поки він прокинеться.
- **Клієнт:** Vercel або Netlify — безплатно, будуйте командою `npm run build` у `client/`, публікуйте вміст `dist/`.
- Не забудьте виставити `CLIENT_ORIGIN` на сервері та `VITE_SERVER_URL` на клієнті відповідно до реальних адрес.

## Що можна доробити далі

- Окремий "нічний" чат тільки для мафії/дона
- Персистентність кімнат (Redis/БД) замість пам'яті процесу — переживе рестарт сервера
- Тривалість фаз, що не зупиняється при перепідключенні (пауза таймера на час дисконекту)
- Аватарки замість першої літери імені, коли камера вимкнена
- Історія завершених ігор (хто ким був, хто виграв)
